# التخطيط الاستراتيجي

[فتح معاينة المطويّة باللغتين](https://moeadnan.github.io/strategic-planning-print-kit-579666/?v=bilingual21#brochure)

بطاقة أعمال ومطويّة واحدة بالعربية والإنجليزية. يجمع كل لوح النص العربي وترجمته الإنجليزية. توضح المعاينة الوجه الخارجي والداخلي وترتيب الألواح، مع خيار تكبير التفاصيل. صورة أحمد صغيرة وبجانبها عبارة مقترحة عن منهج العمل.

**حالة النسخة الحالية:** البطاقة معتمدة وجاهزة للتحميل. المطويّة باللغتين قيد المراجعة؛ تُجهّز نسخة PDF واحدة بوجهين بعد اعتماد التصميم. لم تُحدّث ملفات PDF أو حزم الطباعة.

## الملفات المتاحة

- [بطاقة الأعمال للطباعة التجارية PDF](https://github.com/moeadnan/strategic-planning-print-kit-579666/releases/download/v1.0.0/Business-Card-PRINT-CMYK.pdf)
- [ورقة البطاقة للطباعة المكتبية A4](https://github.com/moeadnan/strategic-planning-print-kit-579666/releases/download/v1.0.0/Business-Card-Office-A4.pdf)
- [تصميم المطويّة باللغتين](brochure.html)

[الإصدار المعتمد السابق v1.0.0](https://github.com/moeadnan/strategic-planning-print-kit-579666/releases/tag/v1.0.0) محفوظ بأصوله. ملفات البروشور السابقة لا تمثّل المطويّة الجديدة باللغتين.

## المقاسات

البطاقة: 90 × 55 مم، وجهان، ونزف 3 مم. المطويّة: 396 × 210 مم مفتوحة، و99 × 210 مم بعد الطيّ، مع أربعة ألواح وثلاث طيّات متعاكسة. اللغتان معًا داخل كل لوح.

تراخيص الخطوط ونسب الصور موثّقة في [CREDITS.txt](CREDITS.txt) ومجلد `assets/`.
