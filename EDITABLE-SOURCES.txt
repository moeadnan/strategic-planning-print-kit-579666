STRATEGIC PLANNING — APPROVED EDITABLE SOURCES / COLLECTION 26

Open index.html in a browser. All fonts and images are local; no internet connection is required for the design preview.

business-card.html: approved bilingual card, 90 x 55 mm trim, front + back, 3 mm bleed.
brochure.html: one Arabic/English brochure, four equal panels, outside + inside, 396 x 210 mm trim, 3 mm bleed.
brochure-ar.html and brochure-en.html are compatibility aliases of the same bilingual brochure.
print-specifications.html: editable Arabic A4 production guide, two pages.

artwork.css, card-refinement.css, typography.css and navy-refinement.css: shared artwork, approved card, local fonts and navy/ivory/copper palette.
brochure-refinement.css and bilingual-refinement.css: final bilingual brochure styling, paired copy and 32 mm circular founder portrait with the brand motif behind it.
preview.css: responsive collection and zoom interface; excluded from artwork printing.
assets/: local fonts and licenses, original portrait, original licensed photographs, generated service icons and card material artwork, and PSO Coated v3 ICC profile.
assets/amman-flag-city.jpg: Daniel Case's original photograph showing Amman and the real Jordanian flag together. CSS provides cropping and colour tint. See CREDITS.txt.

Reproduction tools:
1. python3 tools/build.py --approved
2. node tools/render.cjs --export-pdf
3. python3 tools/produce_pdfs.py
4. python3 tools/preflight.py
5. python3 tools/package.py
Python requires pypdf and reportlab; production requires Ghostscript and Poppler; rendering uses Playwright with Chrome. Adapt the Playwright module path in render.cjs to the local installation.
Use the build review mode and screenshots only for future revisions until the revised design is approved.

The browser's print output is an RGB master. The supplied -PRINT-CMYK.pdf files add profile conversion, crop/fold marks, encoded page boxes and the embedded CMYK output intent.
The printer ZIP includes only the five final handoff PDFs, instructions, credits, ICC profile and preflight report. Intermediate masters and older separate-language brochures are excluded.
Image generation prompts and font/photo licenses accompany the source assets. No foil mask is supplied for this edition.
